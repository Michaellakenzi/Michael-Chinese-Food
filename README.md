# Michael-Chinese-Food
Michael Chinese Food adalah tempat makan yang menyajikan berbagai hidangan khas Tionghoa dengan cita rasa lezat dan harga terjangkau. Kami menyediakan beragam menu seperti mie, nasi goreng, dimsum, capcay, dan hidangan lainnya. Dengan bahan berkualitas dan pelayanan terbaik, kami hadir untuk memberikan pengalaman makan yang nikmat.
